# Student Social Media Addiction Analysis

## Project Overview

This project analyses student social media usage and its relationship with addiction levels, sleep habits, and academic performance using Tableau.

The main objective is to identify usage patterns, understand the factors associated with social media addiction, and present meaningful insights through an interactive dashboard.

## Dashboard Preview

![Student Addiction Analysis Dashboard](Screenshots/DashboardOverview.png)

## Project Objectives

- Analyse social media usage among students.
- Identify the most commonly used social media platforms.
- Explore addiction score distributions.
- Examine daily social media usage across academic levels.
- Analyse the relationship between social media usage and sleep hours.
- Understand the impact of social media addiction on academic performance.

## Tools and Technologies

- **Tableau:** Data visualisation and dashboard development.
- **Microsoft Excel:** Data inspection and preparation.
- **CSV / Excel:** Dataset format.

## Dashboard Highlights

The Tableau dashboard includes:

- Total student count
- Average daily usage hours
- Average addiction score
- Average sleep hours
- Most used social media platforms
- Daily usage by academic level
- Addiction score distribution
- Usage versus sleep hours
- Addiction score by platform
- Academic performance analysis

## Interactive Filters

The dashboard provides filters to explore the data based on available student attributes and categories.

## Key Insights

- Compare the popularity of different social media platforms.
- Explore differences in daily usage across academic levels.
- Examine patterns in student addiction scores.
- Investigate the relationship between usage hours and sleep.
- Explore how social media usage relates to academic performance.
